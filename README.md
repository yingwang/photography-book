# 摄影：从按快门到出片

一本写给摄影中段学习者的中文书。它不从光圈、快门和 ISO 讲起，而是从更容易卡住人的地方讲起：你在现场怎样判断光，怎样决定站位和焦段，怎样知道一张照片该亮还是该暗，回家以后又怎样选片、整理和完成一组作品。

**在线阅读**：[yingwang.github.io/photography-book](https://yingwang.github.io/photography-book/)

## 这本书写给谁

这本书写给已经知道相机怎么用的人。你不需要别人再解释什么是光圈，什么是安全快门，也能看懂 EXIF 里的数字。可是出门拍一天以后，真正让你停下来的，往往不是这些数字，而是另一类问题：为什么看见好光时还是拍不出来，为什么回家选来选去只剩几张，为什么看别人的作品知道好，却说不清自己差在哪里。

书里想处理的就是这些判断。什么样的光值得等，什么样的场景在按快门前就已经不成立，什么时候靠近会更好，什么时候反而该后退，35mm 和 50mm 改变的不只是取景范围，黑白也不是调不好颜色时的退路。摄影从来不只是按下快门那一下，它还包括之前的观看、现场的取舍、回家后的选择，以及你回头看时，能不能看出有些照片其实可以不留下。

## 这本书会少讲什么

它不会花很多篇幅解释基础参数，也不会围绕某一台相机的菜单写。书里会出现 Sony、Fujifilm、Leica、GFX 等系统，但它们只是例子，不是评测对象。它也不是 Lightroom 滑块教程，后期那一章讲的是照片完成过程里的判断，而不是每个按钮该拉到多少。

它也会尽量绕开“摄影是艺术”这类太大的话。现场的问题通常很具体：人站在哪里，脸朝哪边，光从哪来，背景要不要留，暗部要不要沉下去，连拍以后哪一张该留下。把这些问题一个一个想清楚，比背几句漂亮话更能帮到下一次拍摄。

## 怎么读

读的时候可以按顺序来，尤其是前四章。看见、光、曝光、色彩，是后面题材章的底子。直接读人像、街头或风光也不是不行，只是那样更容易先记住几个参数模板，却不知道这些模板为什么成立。

题材章可以先读自己常拍的部分，不熟的题材也可以顺手翻一遍。风光里的耐心，街头里的反应，人像里和人的关系，建筑里的几何，弱光里对暗部的接受，彼此之间都会互相借用。

后期和编辑放在最后，是因为一张本身没有拍好的照片很难被软件真正救回来。先讲怎样拍，再讲怎样完成一张照片，最后讲怎样选出一组作品，这个顺序是有意安排的。
