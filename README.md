# 摄影：从按快门到出片

> 一本系统讲摄影判断力的中文技法书。不教你认光圈快门，教你在每一个真实场景里做出更好的判断。

**在线阅读**：[yingwang.github.io/photography-book](https://yingwang.github.io/photography-book/)

## 这本书的定位

这本书写给已经不是新手、但卡在一个状态里出不去的人。你已经知道相机怎么用，也不再需要别人解释光圈、快门和 ISO。真正卡住你的，是下一步不知道练什么。

- 器材买够了，对着 EXIF 知道每一项是什么意思
- 出去拍一天能按几百张，但回家挑出来发表的总是那几张
- 看别人作品时知道好，但说不清好在哪里
- 想从「会用相机」变成「会出片」，但不知道下一步该练什么

这本书要做的，是把那些隐形的判断显性化。什么样的光值得停下来等，什么样的画面按下去之前就知道会废，什么时候用 35mm 而不是 50mm，什么时候黑白比彩色更对。归根结底，它讲的是从看见到选片之间，那一连串没有写在说明书里的决定。

## 不讲什么

- **基础参数科普**。不解释什么是光圈、快门、ISO，假设你都会。
- **某个具体相机的菜单**。系统无关，例子里会出现 Sony / Fujifilm / Leica / GFX，但都不是评测。
- **修图教程**。Lightroom 哪个滑块怎么拉，YouTube 上有更细的教程。这里只讲后期阶段的判断。
- **「摄影是艺术」那一套**。不灌鸡汤，不讲「用心去看世界」。

## 这本书反对什么

- **机海战术**。一年换四套系统是消费习惯，不是摄影。
- **拉满锐度堆细节**。锐不是好，清晰不是好。
- **HDR 风、过饱和风、Instagram preset 风**。看一眼就知道是用了哪个预设的片子，不是好片子。
- **"决定性瞬间"教条主义**。Bresson 之后已经过去 70 年了。

## 怎么读

按顺序读，特别是前四章。看见、光、曝光、色彩，是后面所有题材章的基础。跳过它们直接进入人像、街头或风光，很容易只学到参数模板，而没有学到判断逻辑。

题材章（第 7 - 12 章）可以挑你常拍的先看。与此同时，建议至少把不熟的题材也翻一遍。风光的耐心、街头的反应速度、人像的引导、建筑的几何，这几种思维可以互相借用。

后期和编辑放在最后，因为它们不该是先决条件。一张本身没拍好的照片，后期救不回来。先讲拍，再讲如何完成一张照片和一组作品，这个顺序是有意安排的。
