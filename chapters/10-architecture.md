# 第 10 章 建筑与城市

> 建筑摄影是几何的题材。线、面、体、空间。每一根线都在告诉眼睛该往哪看。

## 10.1 三类建筑摄影

### 类型一：建筑学纪录（Architectural Documentation）

为建筑师 / 杂志 / 建筑学项目而拍。要求精准记录建筑本身。

特征：

- 透视绝对正（垂直线垂直、水平线水平）
- 光均匀，不戏剧
- 通常移轴镜头（Tilt-Shift）或后期校正
- 干净、客观、没有人

代表：Hélène Binet, Iwan Baan, Hiroshi Sugimoto 早期

### 类型二：建筑作为艺术（Architecture as Art）

把建筑作为美学对象。强调几何、光影、抽象。

特征：

- 不需要透视绝对正
- 用强光影对比
- 局部、抽象、纹理
- 也常常没人

代表：Andreas Gursky, Hiroshi Sugimoto, Candida Höfer

### 类型三：城市生活（Urban）

建筑 + 人 + 生活。介于建筑和街头之间。

特征：

- 有人物（小、远）
- 建筑是舞台
- 几何 + 偶然性
- 时间感强

代表：Joel Meyerowitz, Stephen Shore, Fan Ho（香港），Saul Leiter（纽约）

新手最容易拍出"明信片"的是第一类（拍著名建筑标准角度）和第三类（街头 + 建筑）。第二类最依赖审美训练。

## 10.2 透视：建筑摄影的命门

建筑摄影的第一要务：**透视控制**。

### 为什么透视重要

建筑由直线组成。墙是垂直线，地是水平线。如果你的相机倾斜（仰拍 / 俯拍），垂直线会**汇聚**到一个消失点，建筑看起来"倾倒"或"挤压"。

例：

- 站在高楼下仰拍 → 墙线向上汇聚 → 楼像倒下来
- 站在桥上俯拍 → 墙线向下汇聚 → 楼像沉下去

新手以为这是"动感"，**99% 时候是错的**。建筑学摄影绝不接受这种倾斜。

### 解法一：移轴镜头（Tilt-Shift）

移轴镜头能让你**保持相机水平的同时**抬高视角。垂直线保持垂直。

- Canon TS-E 17mm / 24mm / 50mm
- Nikon PC-E 19mm / 24mm / 45mm
- Sony 没有自家移轴，要转接

移轴镜头贵（10000-20000 RMB），但建筑摄影师必备。如果你认真做建筑，迟早会买。

### 解法二：后期校正

非建筑师摄影师常用：

- 拍的时候让相机水平（甚至略俯）
- 让建筑顶部留出余量
- 后期 Lightroom / Photoshop 用透视校正工具拉直
- 损失边缘像素，所以要拍高分辨率

### 解法三：站远 + 长焦

距离够远的时候视角变小，透视影响小。

- 用 50-85mm 站远拍建筑
- 视野窄但变形小
- 缺点：很难找到能站这么远的位置

### 解法四：接受不正

如果你拍的是"建筑作为艺术"，可以故意夸大透视。极端仰拍 + 鱼眼出来的画面是合法的艺术选择。

但要**故意**这么做，不是因为不会校正所以接受。

## 10.3 建筑摄影器材

### 镜头

**最有用三颗**：

- 16-35mm f/4 / 17-35mm：90% 建筑用这一颗
- 24-70mm f/4：补中段、室内
- 70-200mm f/4：远景压缩、局部

**移轴**（专业级）：

- 17 / 24 移轴
- TS-E 17mm 是建筑摄影神器（Canon）

### 三脚架

建筑摄影 80% 都用三脚架：

- 慢门
- 精确构图（每根线都要对齐）
- 包围曝光
- 室内弱光

要求：稳、能精确调水平。带气泡水平仪或电子水平仪。

### 滤镜

- CPL：减少玻璃幕墙反光
- ND：白天慢门拍人流
- ND1000：白天 30s 慢门拍人流变虚影

### 相机

任何全画幅都行。**高分辨率有用**（4000 万像素+），因为：

- 后期透视校正会损失像素
- 建筑常用大幅打印
- 精细线条需要分辨率

## 10.4 建筑摄影的光

建筑光不像人像那样"找好光时段"，建筑很多时候**用什么光都能拍**。但每种光对应不同效果。

### 直射阳光

**优点**：纹理、光影、戏剧。
**缺点**：高反差、半边亮半边死黑。
**适合**：抽象、几何、有戏剧性的现代建筑。
**陷阱**：拍正面、要看建筑的"正脸"时，太硬会一面亮一面黑。

### 阴天

**优点**：均匀、所有面都看清、没有死阴影。
**缺点**：戏剧弱、平、单调。
**适合**：建筑学纪录、看建筑全貌。
**陷阱**：颜色淡、反差不够。

### 黄金时刻

**优点**：暖色、长投影、戏剧性。
**适合**：有大面玻璃的建筑（反射夕阳）、传统建筑（暖色 + 木石质感）。
**陷阱**：东西向问题 - 黄金时刻只能拍向东 / 向西的那一面。

### 蓝调时刻

**优点**：蓝天 + 建筑灯亮起。颜色对比戏剧。
**适合**：现代建筑、玻璃楼、夜景城市。
**陷阱**：窗口窄（25-40 分钟），要提前到位。

**最适合现代城市建筑的就是蓝调时刻**。原因：

- 天空有色（不是死黑）
- 窗户灯亮（建筑变成"发光体"）
- 反差适中
- 颜色对比强（蓝 + 黄橙）

### 雨后 / 雾中

**优点**：戏剧、神秘、独特。
**适合**：一切建筑。雾里的高楼像浮岛。

## 10.5 建筑摄影的构图

### 思维一：找几何

建筑由几何构成。看一栋建筑先找：

- 主导线（垂直、水平、对角）
- 重复（一排窗、一组柱、一片瓷砖）
- 对比形状（一个圆 vs 一个方）
- 留白（一面纯墙）

让画面里只剩**最强的几何**。其他东西能去就去。

### 思维二：对称 vs 不对称

中轴对称：

- 国家级建筑（教堂、宫殿、政府）
- 让画面庄重、稳定
- 拍时镜头精确居中
- 一定要竖直水平精确

非对称（占主体）：

- 大部分现代建筑
- 让画面动态、有视觉重量
- 主体偏一侧，留出"呼吸空间"

### 思维三：主导线

每张建筑片都应该能识别出**主导线**。

- 一根强对角线
- 一组平行垂直线
- 一条向远处消失的水平线
- 一个 S 曲线（旋转楼梯、曲线建筑）

主导线决定眼睛进入画面的方向。**没有主导线 = 画面散**。

### 思维四：尺度

建筑摄影常用一个小元素（人、车、椅子）来表达建筑的**大**。

- 一个站在巨大建筑下的小人 = 建筑变得有尺度
- 一辆车停在巨型空间里 = 空间感更强

但**只放一个**。多个就乱。

### 思维五：抽象

把建筑拍到抽象到只剩形状：

- 玻璃幕墙的反射变成纯几何
- 屋顶的瓦排列变成纹理
- 阴影投在墙上变成画

这种处理在第二类（建筑作为艺术）里最常见。

## 10.6 城市摄影

城市 = 建筑 + 人 + 时间。比单纯建筑摄影复杂一层。

### 城市摄影的层次

**层次一：天际线**

- 站高处 / 山上 / 桥上 / 高楼顶
- 拍一座城的整体轮廓
- 蓝调时刻最佳
- 焦段：24-70mm

**层次二：街区**

- 一条街、一个广场、一个 mall
- 建筑 + 街景
- 各种焦段

**层次三：街角**

- 一个具体角落
- 接近街头摄影
- 35mm + 主体

层次越深越接近街头。

### 城市生活的捕捉

接近第 8 章街头。但这里强调**建筑作为舞台**：

- 让画面里建筑占大比例
- 让人作为"标点"出现在建筑中
- 建筑的几何 + 人的瞬间

Saul Leiter 的纽约、Fan Ho 的香港、Alex Webb 的城市片都是这种思维。

## 10.7 室内建筑摄影

商业室内（酒店、餐厅、商店、住宅）的拍摄。

### 关键技巧

**技巧一：关掉所有灯，分别打开**

- 一组照片：白天关所有灯，单纯自然光
- 另一组：晚上开灯，人造光
- 后期合成（高级）

新手做法：把所有灯都开，结果混色光（窗光 5500K + 暖白灯 3000K + 卤素灯 2700K），脏。

**技巧二：广角不要太广**

很多人室内拍一上来上 16mm。结果墙四角变形夸张，沙发拉成长椭圆。

**用 24mm**。够广，不夸张。

**技巧三：透视校正**

室内拍全景几乎都有仰角问题。后期校正或前期用移轴。

**技巧四：包围曝光**

室内反差大（窗外亮 + 室内暗）。-2 / 0 / +2 三张，后期合成。

**技巧五：站位**

不要从门口拍。**蹲下、站到对角、靠墙**。看最有戏的角度。

### 关键参数

- 三脚架
- 光圈 f/8（最锐 + 全景深）
- ISO 100
- 慢门（1-30s 都正常）
- 拍 RAW
- 关闪光灯

## 10.8 几个常见建筑题材

### 题材一：摩天大楼

**视角**：

- 仰拍底部（极戏剧，但要校正透视或故意夸大）
- 远处长焦（等高视角，最干净）
- 顶部俯瞰（站到对面更高建筑或山）

**最佳光**：蓝调时刻 + 灯亮。

### 题材二：欧洲老城

**视角**：

- 街道两侧夹起的"画框"
- 教堂广场
- 河边城市天际线
- 屋顶（如果有公共观景台）

**最佳光**：黄金时刻（暖光打在石头墙上）。

### 题材三：日式建筑

**视角**：

- 极简对称
- 屋檐 + 庭院
- 雪后 / 樱花季
- 雾天

**最佳光**：阴天 / 雾天 / 雪后。日式美学不依赖戏剧光。

### 题材四：现代极简建筑（Tadao Ando 派）

**视角**：

- 一面墙 + 一束光
- 几何切割
- 留白比建筑多

**最佳光**：直射阳光让光影戏剧化。

### 题材五：老厂房 / 工业遗迹

**视角**：

- 巨大空间感
- 锈、剥落、纹理
- 单点透视（一条走廊延伸到远处）

**最佳光**：阴天均匀光、室内人造光、雾天。

### 题材六：宗教建筑（教堂、寺庙、清真寺）

**视角**：

- 建筑外（黄金时刻 / 蓝调）
- 室内（自然光从窗 / 顶照下）
- 细节（雕刻、彩窗、装饰）

**注意**：很多宗教建筑禁止拍照或禁用三脚架。**进门先确认**。

## 10.9 小结

- 建筑摄影分三类：纪录、艺术、城市
- 透视控制是命门：移轴或后期校正
- 蓝调时刻是现代建筑最佳时段
- 阴天 / 雾天最适合东方建筑美学
- 构图找几何：主导线、对称 / 不对称、尺度
- 室内拍摄关闪光、用三脚架、慢门、单一色温
- 雨后雾中是建筑摄影的金牌时段

## 10.10 练习

**练习 10.1：透视校正一周。**
找一栋建筑，从不同角度（正面、仰、俯、侧）各拍一张。回家做透视校正。看校正前后的差异。

**练习 10.2：蓝调时刻城市。**
一个城市制高点（高楼观景台、桥、山顶）。蓝调时刻去拍 30 分钟。每 5 分钟拍一张。回家看哪一刻最好。

**练习 10.3：几何抽象。**
拍 10 张完全抽象的建筑（看不出是哪栋楼，只是纯几何）。各种角度、各种局部。

**练习 10.4：尺度对比。**
一组三张：一栋建筑 + 远处一个人 / 一辆车 / 一条狗。让小元素出现在画面里给建筑"定标尺"。

**练习 10.5：同一建筑十种拍法。**
找一栋你常路过的建筑，连续十天每天用一种新的方式拍它。十天后并排看，会发现"一个建筑能说多少话"。
