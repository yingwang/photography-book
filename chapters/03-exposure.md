# 第 3 章 曝光

> 曝光不是公式。曝光是一个判断：在动态范围有限的传感器上，决定保留什么、放弃什么。

## 3.1 曝光不是 18% 灰

老教科书会告诉你"曝光是测量场景反射率，让 18% 灰被记录为中灰"。这没错，但它解释的是测光表的工作原理，不是**怎么决定一张片子的曝光**。

正确思考方式：

```
场景里有一个亮度范围（比如最暗到最亮差 10 档）
传感器有一个动态范围（现代全画幅大约 14 档）
你的曝光决定 = 场景亮度范围 → 落在传感器哪一段
```

这个"落在哪一段"才是曝光的本质。它有三种典型选择：

1. **常态**：场景亮度居中落，亮的不爆、暗的不死
2. **保高光**：让最亮的部分刚好不爆，暗部牺牲
3. **保暗部**：让最暗的部分有细节，高光爆掉一点也接受

你做的不是"找一个对的曝光"。是**在传感器有限的动态范围里选一个偏移**。

## 3.2 直方图：看这个，不看预览

相机屏幕的预览图骗人。亮度受屏幕亮度、环境光、显示模式影响，看着对的可能曝光全错。

**看直方图**。直方图是这张照片所有像素的亮度分布。横轴从左（黑）到右（白），纵轴是像素数量。

判断标准：

- 直方图碰右边墙 = 高光过曝（白成一片，没细节）
- 直方图碰左边墙 = 暗部死黑（黑成一片，没细节）
- 直方图整体居中 = 中等曝光，但不一定对

**注意"对"的曝光不一定是直方图居中**。雪景应该偏右（不然雪是灰的），夜景应该偏左（不然失去夜的感觉）。直方图只告诉你**有没有信息丢失**，不告诉你画面好不好看。

### 高光警告（斑马线 / 闪烁）

打开"高光警告"功能（Sony 叫斑马线、Fujifilm 叫高光警告、Canon/Nikon 叫闪烁）。设置阈值在 100% 或 95-100%。当画面里某区域过曝，那一块会闪烁/有斜线提示。

这是比直方图更直观的工具。**拍人像的时候开斑马线，对脸部高光设到 95%，脸上一闪烁就降一档**。比测光准。

## 3.3 三角形：光圈、快门、ISO

三个变量决定曝光，每个变量有副作用：

| 变量 | 控制 | 副作用 |
|------|------|--------|
| 光圈 | 进光量 | 景深（小光圈深、大光圈浅） |
| 快门 | 进光时间 | 运动模糊（快快门冻结，慢快门拖影）|
| ISO | 信号放大 | 噪点（高 ISO 噪点多） |

你必须**先决定景深和运动需求**，再让 ISO 兜底：

```
我要的景深 → 光圈
我要的运动状态 → 快门
剩下让 ISO 顶住
```

### 光圈优先 (A 模式)：90% 场景的默认

设光圈 → 相机给快门 → 你管 ISO（手动或 Auto）。这是绝大多数题材的默认模式：

- 人像：f/1.4 - f/2.8（看你要多浅景深）
- 街头：f/5.6 - f/8（一切都清楚）
- 风光：f/8 - f/11（最锐区间）
- 室内/弱光：f/1.4 - f/2.8（最大进光）

设完光圈，看快门多少。**快门低于安全快门就要警觉**。

### 安全快门

手持不抖的最低快门：

- 一般规则：1 / 焦距（35mm 焦段对应 1/40s 左右）
- 有防抖（IBIS）：1 / 焦距 / 4 - 1 / 焦距 / 8
- 你的手稳不稳：自测

**这个数字只保证"你不抖"，不保证"主体不抖"**。拍走路的人，至少 1/250s。拍跑动的小孩、宠物、街头快速场景，1/500s - 1/1000s。

### 快门优先 (S/Tv 模式)：动态题材

设快门 → 相机给光圈 → 你管 ISO。用在：

- 拍移动的人/动物（设 1/500s - 1/1000s）
- 拍水流（设 1/2s - 几秒，要拖丝感）
- 拍夜景车流（设 5-30s，要光轨）

### M 模式 + Auto ISO：被低估的最强组合

很多老法师把"M 模式 + 手动 ISO"当作专业的标志。其实在大多数现实场景里，**M 模式 + Auto ISO** 才是最实用的：

- 你设光圈（控制景深）
- 你设快门（控制运动）
- 相机自动 ISO（适应亮度变化）
- 用曝光补偿微调

这等于"三个都被控制"+"自动适应光线"，你只在亮度跨度大的时候动一下补偿。街头摄影、活动记录、亲子拍摄都靠这个。

## 3.4 测光模式

测光模式告诉相机"我要测哪一块的亮度"。

| 模式 | 测哪 | 什么时候用 |
|------|------|----------|
| 评价 / 矩阵 | 整个画面加权 | 默认。90% 场景 |
| 中央重点 | 中央区域（约 60-80%）|主体大致居中 |
| 点测 | 一个小点（1-3%）| 强反差场景，给最重要部分定曝光 |
| 局部 | 中央较大块（约 10%）| Canon 老一代特有，少用 |

### 大多数时候：评价测光

现代评价/矩阵测光算法（特别是 Sony/Fujifilm/Canon 最近几代）已经非常聪明，对绝大部分场景给的曝光都是合理起点。**默认就用它**。

### 真正需要点测的时候

强反差场景，主体只占画面一小块，背景巨亮或巨暗。例子：

- 舞台聚光灯下的歌手（背景暗、主体亮）
- 雪地里的人（背景白、主体相对暗）
- 逆光下的人脸（背景天空亮、人脸暗）

在这些场景下评价测光会被背景拉跑：拍歌手会过曝（相机以为整体太暗），拍雪地里的人会欠曝（相机以为整体太亮）。

**点测对准主体（脸）**，让相机只给那一小块测光。然后曝光补偿微调（脸偏亮加 +0.7，偏暗的肤色 +0.3 等）。

## 3.5 曝光补偿：你说了算

测光给出一个建议曝光。**你不一定同意**。曝光补偿（EV +/-）就是你对相机说"加亮点"或"压暗点"。

什么时候用：

- 雪景：+1 ~ +2（不补的话雪变灰）
- 黑色物体（黑车、黑猫、黑墙）：-0.7 ~ -1.5（不补的话黑变灰）
- 逆光：+1 ~ +2（不补的话主体死黑）
- 夜景：-0.7 ~ -2（不补的话夜变白天）
- 高调白：+0.7 ~ +1（让画面亮、薄、轻）
- 低调暗：-1 ~ -2（让画面深、重、戏剧）

**记一个口诀**：白加黑减。雪、白墙、白色衣服 → 加。煤、黑墙、黑色衣服 → 减。原因是测光默认所有场景平均到 18% 灰，所以白会被压灰、黑会被提灰，需要你反向补回来。

## 3.6 ETTR（曝光向右）：保留信息的策略

"Expose To The Right" - 在不让高光过曝的前提下，尽量让直方图往右靠。

原理：传感器的信号是线性的，越亮的级别能记录的灰阶数越多。最亮的一档能记录 4096 级灰阶，最暗的一档只能记录 32 级。所以**亮的部分细节多，暗的部分细节少**。

实操：

- 拍摄时让直方图右端紧贴右墙但不爆
- 后期把整体压暗回来
- 这样**暗部噪点少了一大截**

ETTR 适合：

- 风光（低反差为主，可以推到右）
- 高 ISO 弱光（让信号更强，回来压暗 = 降噪）
- 拍 RAW（JPEG 没那么多回旋空间）

不适合：

- 高反差场景（推不动，一推就爆）
- 你不愿意后期的人

## 3.7 包围曝光：实在不确定就一组拍

包围曝光（Bracketing）= 同一画面拍多张不同曝光（比如 -1 / 0 / +1），回家挑一张或合成。

什么时候用：

- 风光（特别是日出日落，光变化快）
- 特别贵重的场景（婚礼、纪念、不可重来）
- 高反差需要 HDR 合成

什么时候不用：

- 街头（来不及，主体走了）
- 人像（表情不同步）
- 一切动态题材

现代相机有自动包围功能（AEB）。打开之后按一次快门拍 3-5 张。

## 3.8 几个常见曝光困境

### 困境一：晴天人像，半边脸亮半边黑

太阳从 90° 来，脸两侧反差 2-3 档。

解法：

- 走到阴影里（最简单）
- 用反光板补阴影侧（专业做法，便携反光板 50 块钱）
- 用闪光灯高速同步补光（最讲究）
- 让被拍者转头，把暗侧朝向相机变成"低调光"（艺术处理）

### 困境二：室内人对着窗户

主体在屋内，背景是亮窗户。反差大概 5-7 档。

解法：

- 给窗户曝光 → 主体剪影（如果你要剪影）
- 给主体曝光 → 窗户全白（如果你要白窗的轻飘感）
- 走到窗边让主体侧对窗户（侧光，反差降到 2-3 档）

### 困境三：博物馆 / 教堂内部

非常暗，只有局部聚光。反差大、亮度低。

解法：

- 大光圈（f/1.4 - f/2.8）
- 高 ISO（3200 - 12800，现代相机能扛）
- 慢快门（手持极限 1/30s 配防抖）
- 找柱子/墙倚靠当三脚架
- 评价测光，点测主体重要部分（圣像、雕塑），曝光补偿 -1 ~ -2 保留教堂的暗调氛围

### 困境四：演唱会 / 舞台

主体被聚光灯照到，背景全黑。反差极大。

解法：

- 点测主体
- 曝光补偿 -0.7 ~ -1（聚光灯本来就亮，要保高光）
- 高 ISO（动作快、不能慢快门）
- 拍 RAW（后期回旋空间）

### 困境五：雪景 / 雾景

整体偏白，反差很低。

解法：

- 雪：+1 ~ +2（不然变灰）
- 雾：直方图偏右，但不要爆
- 拍 RAW，后期微调
- 注意保留质感（不要把雪全调白成纸，留点蓝阴影）

## 3.9 RAW 的曝光宽容度

RAW 比 JPEG 在曝光上宽容 2-3 档。意思是：

- 欠曝 2 档 → 后期能拉回来，损失噪点容忍度
- 过曝 1 档 → 高光大概率回不来（一旦剪掉就是没了）

所以**宁欠勿过**。如果不确定，曝光补偿 -0.3 到 -0.7。

但 ETTR（曝光向右）的策略是反过来：尽量推到右但不爆。两者并不矛盾 - 一个是"出错时往哪边偏"，一个是"做对时怎么最大化信息"。

## 3.10 小结

- 曝光是判断：传感器动态范围有限，决定保留什么
- 看直方图，不看预览
- 拍前先决定景深和运动，让 ISO 兜底
- M + Auto ISO 是最实用的现代模式
- 测光默认评价，需要时切点测
- 曝光补偿白加黑减
- RAW 宁欠勿过，但 ETTR 可以推到右
- 高反差场景必须选保留谁

## 3.11 练习

**练习 3.1：直方图速读。**
出门一天，每按一张快门马上看直方图（不要看预览）。看 30 张之后你应该能从画面预判直方图大致形状。

**练习 3.2：高光警告训练。**
开斑马线（设到 100%）。拍人像 30 张，每次注意脸上有没有闪烁。有就降曝光直到不闪。回家看片子的高光控制。

**练习 3.3：包围曝光风光。**
日落黄金时刻找一个风光机位，开包围曝光（-1 / 0 / +1）。拍 5 个机位。回家三张并排看，每个机位选一张并说为什么。

**练习 3.4：M + Auto ISO 街头。**
设 f/5.6、1/500s、Auto ISO（上限 6400）。出门拍街头一小时。让相机自适应光线。回家看 ISO 跨度多大，对应画面有什么变化。

**练习 3.5：曝光补偿快反应。**
找一个反差大的场景（雪地、暗厅、逆光人）。先按相机默认拍，然后判断需要什么补偿，再拍一张。比较两张哪个对。重复 10 次。
