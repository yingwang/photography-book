# 第 7 章 人像

> 人像摄影从来不仅是把一张面孔记录在底片上。真正穿透镜头、留在画面中的，是拍摄者与被摄者之间的交流与理解。

---

## 人像从关系开始

一张自然动人的人像照片，往往不会诞生在被摄者刚坐下、摆出标准微笑的最初几秒。

很多时候，需要拍摄者耐心地等一等。

在镜头刚刚对准的最初几分钟里，人们往往会下意识地注意自己的举止：肩膀是否端正、笑容是否自然、手放在哪里合适。此时被摄者呈现的，往往是他希望展现给外界的社交状态。

这一阶段可以拍到端正清晰的照片，但那往往带着被审视时的紧绷感，未必是他最放松的常态。

值得等待的，是他暂时忘却镜头存在的时刻。

那样的时刻往往很平常：或许是他低头整理衣角，或许是与身旁的人说了一句玩笑话，或许是轻叹了一口气，或是目光从镜头移开、看向窗外。

在这一两秒内，他不再刻意表现“正在被拍照”，神态随之放松，原本真实的性情与微表情才自然显露出来。

人像摄影中耐读的画面，往往就出现在这些不经意的瞬间。

摄影师需要掌握光影的分布、焦段的选择与构图的机位；但技术最终要服务于画面的真实感，让照片中的人物显得生动自然，而非生硬呆板。

## 技术之前，先建立信任

人像创作中，拍摄者与被摄者之间的互动关系直接影响着成片的质感。常见的拍摄关系大致可分为三类：

**摆拍肖像（Posed Portraiture）**：被摄者明确知晓拍摄正在进行，并主动配合。包括个人写真、商业人像、团队合影等。拍摄者对光线、姿态、服装与背景有较大的主导权；被摄者也期待获得满意的成片。

**环境肖像（Environmental Portraiture）**：被摄者处于他熟悉的工作或生活空间中——木匠在工坊、医生在诊室、学者在书房、厨师在厨房。环境是人物身份与生活状态的重要组成部分，构图时需兼顾人物与环境的关系。

Arnold Newman 为作曲家 Stravinsky 拍摄的环境肖像堪称经典：作曲家坐在画面的左下角，占据大半画面的则是立起琴盖的黑色大三角钢琴——琴盖的几何形状与人物构成了鲜明的呼应，把音乐家的身份与空间紧密融合在一起。

**纪实抓拍与抓取（Candid Photography）**：被摄者专注于自己的事情，未特意配合镜头。包括街头人文、家庭日常记录等。此时拍摄者主要依赖观察与预判，捕捉生活中的自然神态，尽量减少对现场的打扰。

Vivian Maier 在街头安静地观察；Saul Leiter 从窗后静看行人；Helen Levitt 记录街头孩童的游戏。他们都倾向于不打扰现场，记录日常生活的本来样貌。

在人像摄影中，尊重被摄者是基本的原则：
*   在非公开场合拍摄陌生人时，尽量通过眼神或言语表达善意与征询；
*   拍摄结束后，真诚地让对方查看成片，必要时主动提供照片；
*   商业使用时，签署正规的肖像授权协议；
*   后期修图时，适度修正临时性瑕疵（如偶发的痘痘），保留人物本来的面貌特征，避免过度磨皮导致失真。

拍摄者应当时常自省：**我镜头下的人物，是否在照片中展现了他真实而有尊严的一面。**

## 光怎样塑造一张脸

面部的立体感主要依靠光影的起伏来体现。观察面部光线时，可以重点关注三个要素：**鼻影的走向、暗部的层次、以及眼中的眼神光。**

根据主光源相对于面部的位置，人像摄影中常归纳出几种经典光型：

| 光型名称 | 主光源位置 | 面部阴影特征 | 视觉感受 |
|---|---|---|---|
| 蝴蝶光（Paramount Light） | 正前上方、略高于视线 | 鼻下方有一小片对称的阴影 | 凸显颧骨轮廓，面部干净端庄 |
| 环形光（Loop Light） | 前方约 45°、略高 | 鼻翼一侧有小巧阴影，不与颊影相连 | 自然柔和，通用性强 |
| 伦勃朗光（Rembrandt Light） | 侧前方约 45°、角度稍高 | 暗侧脸颊形成三角形光斑 | 阴影分明，富有立体感与沉稳气质 |
| 分割光（Split Light） | 正侧方 90° | 面部一半亮一半暗 | 对比强烈，戏剧感分明 |

在此基础上，还需结合**宽光与窄光**的方向选择：

*   **宽光（Broad Lighting）**：面部转向一侧时，光线照亮的是**面向镜头的大半侧脸**。在视觉上有略微拉宽脸型的效果，适合脸型偏瘦者。
*   **窄光（Short Lighting）**：光线照亮的是**背向镜头的小半侧脸**，面向镜头的大半侧脸处于柔和的阴影中。视觉上有收窄脸型的效果，立体感更强，是古典人像中常用的用光方式。

```mermaid

    A --> C["光照在远侧小半脸<br/>窄光：立体显瘦"]
```

确定主光位置后，还需通过辅助光或反光板调节**光比**（Lighting Ratio）：

*   **1:1 至 2:1**（亮暗面相差 0–1 档）：光影柔和，适合清新淡雅的肖像；
*   **3:1 至 4:1**（相差约 1.5–2 档）：层次分明，立体感舒适，为经典人像的常用光比；
*   **8:1 及以上**（相差 3 档以上）：反差强烈，暗部深沉，适合表现硬朗与戏剧感。

## 焦段与机位

不同焦段在人像中的特点：

*   **35mm**：适合带环境的人像（全身与半身），交代人物与空间的互动，拍摄时需注意人物居中或适度控制边缘变形；
*   **50mm**：透视自然，适合半身与全身人像，视角平实亲切；
*   **85mm 至 135mm**：经典肖像焦段，背景适度虚化，五官比例自然端庄，适合胸像与面部特写；
*   **广角（24mm 及以下）**：在人像特写中容易导致五官拉伸（靠近时大鼻子、面部变形），通常仅用于特定创意的环境全景，且人物面部应避免靠近画面边缘。

机位高度亦会影响人物的气质：
*   **平视机位**：相机与人物眼睛处于同一高度，视线平等亲切；
*   **微仰拍**：机位略低于视线，能增强人物的挺拔感；
*   **微俯拍**：机位略高于视线，面部显小，但角度过大会显得头大身小。

## 姿态与引导

引导被摄者时，清晰、具象的指引往往比抽象的口令更有效：

1.  **具象动作优于抽象形容**：“请把重心放在后脚上”、“手指轻轻搭在桌沿”，比“请表现得自然一些”更容易执行。
2.  **给双手安排合理的归宿**：插兜、扶眼镜、端咖啡杯、翻书页，避免双手无处安放带来的局促感。
3.  **微调身体角度**：身体与镜头呈 30° 至 45° 夹角，通常比正对镜头更显修长放松。
4.  **在交谈中抓拍**：边聊边拍，观察对方说话间歇或倾听时的自然眼神，在不经意间捕捉神态。

## 黑白人像的运用

将人像转为黑白，能够去除色彩的干扰，使观者的注意力集中在人物的五官结构、眼神神态与明暗光影上。

适合转为黑白的人像通常具备：
*   清晰的光影反差与立体骨骼轮廓；
*   丰富细腻的中间调层次；
*   富有故事感的神态或饱经风霜的皮肤质感。

若原片光线平淡、反差不足，单纯去色容易使画面显得灰暗无神。

## 练习

在窗边为朋友拍摄肖像，分别尝试正面平光、45° 侧光（环形光与伦勃朗光）、以及 90° 侧光（分割光），观察阴影对脸型的修饰效果。

使用 50mm 或 85mm 镜头，分别拍摄面向窗户的“宽光”与背向窗户的“窄光”，对比两者的视觉差异与脸型变化。

为一位有特定手艺或爱好的朋友拍摄一组环境肖像（如在书房、画室或厨房），尝试用 35mm 焦段将人物与工作环境有机融合在画面中。
