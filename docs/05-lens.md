# 第 5 章 镜头语言

> 焦段不是"拍多远"。焦段是用什么角度看世界。换镜头 = 换思维。

## 5.1 焦段不是放大缩小

新手的理解：长焦能拉近、广角能容下更多。这只对了一半。

更准确的理解：**焦段决定空间被压缩还是被拉伸**。同一个场景，用 24mm 和用 200mm 拍出来是两个完全不同的空间感受：

- **广角（24mm 以下）**：前景被夸大，背景被推远。立体感强，纵深拉得长。
- **标准（35-50mm）**：接近人眼视角，空间关系自然。
- **中长焦（85-135mm）**：背景被拉近、压缩。前后景距离感被压缩。
- **长焦（200mm 以上）**：极度压缩。远处的山看起来贴在背景人物身后。

这是镜头语言的本质。同一个人站在同一个地方，用 24mm 拍他和用 135mm 拍他，画面里他和背景的关系**完全不同**。

## 5.2 各焦段的特性和适用题材

### 14-24mm 超广角

视角：90-110°
特性：极度拉伸前景、压扁建筑变形、收很多东西进画面

适合：

- 风光（要把山和前景一起进画面）
- 室内（小空间需要大视角）
- 建筑（仰拍需要宽视角，但要后期校正畸变或买移轴）
- 戏剧性人像（人物 + 巨大环境）

不适合：

- 普通人像（脸会变形，靠近边缘的脸尤其惨）
- 远处主体（拍出来太小）

陷阱：超广角"看起来内容很多"，但 90% 进框的内容是干扰。**要主动用前景**，不能站着随便按。

### 28mm 广角

视角：~75°
特性：广但不太变形，前景拉伸不夸张

适合：

- 街头（环境包进来 + 主体）
- 风光的中近景（不那么夸张的视角）
- 旅游纪实
- Ricoh GR、Sony RX1R 的固定焦段

28 是"一个人 + 他所在的世界"的视角。不是给主体特写的，是讲故事的。

### 35mm 准标准 / 街头之王

视角：~63°
特性：自然、稍微宽一点，能进环境也能聚焦主体

适合：

- 街头（最经典街头焦段）
- 环境人像（人 + 一点环境）
- 纪实
- 旅游
- 餐桌（坐对面拍朋友脸 + 食物）

**35mm 是这本书最推荐的"第一颗定焦"**。如果你只能买一颗定焦，买 35。理由：

- 视角接近人看一群人时的视角
- 在街上既能拍特写也能进环境
- 不需要走得太近（28mm 要走得近）
- 不会变形（24mm 会变形）
- 大光圈版本（f/1.4-1.8）虚化够用

### 50mm 标准

视角：~46°
特性：接近单眼看一个东西时的视角

适合：

- 单人人像
- 静物
- 安静的纪实
- Bresson 一辈子用 50mm

50mm 的争议：有人觉得它"无聊"。这是误解。50mm 之所以经典是因为它**没有视觉戏剧性**，画面靠的是构图和瞬间，不靠视角戏法。

新手买 50mm 是因为便宜（每个系统都有 nifty fifty f/1.8，几百块）。十年的人买 50mm 是因为它逼你做判断。

### 85mm 人像之王

视角：~28°
特性：背景压缩、虚化好看、拍人脸不变形

适合：

- 人像（半身、特写）
- 婚礼远拍
- 舞台
- 一切"主体明确 + 背景需要消失"的场景

陷阱：85 容易让人懒。所有片都套路化（虚化奶油、人脸正面、闭嘴微笑）。要用 85 拍出新意，构图和光必须更下功夫。

### 135mm

视角：~18°
特性：极强压缩、极强虚化、需要距离

适合：

- 全身人像（让人物从环境里"剥离"）
- 街头远摄（不打扰对方）
- 风光特写（拉一座山或一棵树）

很多老法师推 135mm 当人像首选。它的画面感**比 85 更高级**，但需要的拍摄距离更远，室内常常摆不开。

### 200mm+ 长焦

视角：12° 以下
特性：极度压缩、需要稳定支持

适合：

- 体育
- 野生动物
- 风光特写（远山压缩）
- 演唱会舞台

不适合大部分日常题材。除非你专门拍这些，不必要买。

### 24-70 / 24-105 / 24-200 这类变焦

视角：可变
特性：方便、灵活、画质比同代定焦差一截、光圈通常 f/2.8 或 f/4

适合：

- 婚礼（不能换镜头）
- 旅行（一颗解决）
- 工作记录（速度优先）

不适合：

- 训练判断（变焦让你不思考）
- 极致画质
- 极端弱光（最大也只 f/2.8）

变焦不是错的。但**新手用变焦的进步速度比定焦慢一倍**。如果你想真练，请放弃变焦至少半年。

## 5.3 视角的"心理距离"

不同焦段拍出来的画面，让观众感觉**离主体多远**：

- 24mm：观众"在场"。仿佛你站在画面里。
- 35mm：观众"靠近"。像和主体一桌。
- 50mm：观众"对话"。你看着对方。
- 85mm：观众"凝视"。你在看他但他没看你。
- 135mm：观众"窥视"。你远远看着，他不知道。
- 200mm+：观众"监视"。距离感很强。

这个心理距离比物理距离重要。

街头摄影的灵魂就在这个心理距离上。Bresson 用 50mm，Klein 用 28mm，Daido Moriyama 用 28mm + 闪光灯，这都不是器材选择，是**他们想让观众站在哪里**的选择。

## 5.4 景深：浅景深不是炫技

景深由三个变量决定：

1. **光圈**：越大（数字越小）景深越浅
2. **焦距**：越长景深越浅
3. **拍摄距离**：越近景深越浅

新手第一年特别迷恋"奶油虚化"。f/1.4 拍人，前后糊一片。问题是：

- 眼睛睛清楚但鼻尖虚了（焦平面太浅）
- 整张脸里只有一只眼睛对焦
- 虚化没有美感（小光圈 + 不好的镜头会出"二线性"）
- 画面只剩下一个被虚化包围的脑袋，没有空间

**真正会用景深的人会"看景深所代表的关系"**：

- 浅景深 = "这是关于他的，背景不重要"
- 深景深 = "这是关于他和他所处的世界的"
- 中景深 = "他和身边的某个东西有关系"

按之前问：**这张需要多少景深？景深要传达什么？**

### 景深参考表

下面是大概，具体看镜头：

| 设置 | 焦平面在 2m 处的景深 |
|------|----------------------|
| 35mm f/1.4 | ~10cm |
| 35mm f/2.8 | ~25cm |
| 50mm f/1.4 | ~5cm |
| 50mm f/2.8 | ~12cm |
| 85mm f/1.4 | ~2cm |
| 85mm f/2.8 | ~5cm |
| 85mm f/5.6 | ~10cm |
| 24mm f/2.8 | ~50cm（很深） |
| 24mm f/8 | 整个画面都清楚 |

**85mm f/1.4 的景深 2 cm**，对焦在眼睛上鼻尖就虚。新手要熟悉这个事实。

## 5.5 透视：站位决定空间感

同一个焦段，**站位变了透视就变了**。

实验：
- 用 35mm 站离主体 1 米拍 → 主体大、背景被夸张推远
- 用 35mm 站离主体 5 米拍 → 主体小、背景跟主体距离合理

换镜头不变站位 vs 不换镜头变站位，前者改变视野，后者改变透视。透视改变空间感。

**新手的常见错误**：用 35mm 站很远拍主体，导致主体小、背景远。然后觉得"35mm 不行"，换 85mm。其实问题是**没靠近**。

Robert Capa 那句"如果你的照片不够好，那是因为你离得不够近" - 字面意思就是这样。

## 5.6 镜头光学常识

### 锐度：拉到 f/5.6-f/8 是大部分镜头的最锐区间

绝大部分镜头在最大光圈不是最锐的。f/1.4 用了 f/1.4 的虚化但牺牲了锐度。**收一档到两档**会显著锐很多。

如果你不需要最大景深的虚化，**默认 f/2.8-f/5.6**。

### 暗角

广角镜头的边缘通常会暗。这不是缺点，可以做画面引导（暗角天然把视线推向中心）。后期可以加重暗角作为风格化。

### 畸变

广角有桶形畸变（直线弯曲外凸）。长焦有枕形畸变（直线弯曲内凹）。一般 50mm 附近最少。

后期软件能校正。但不能 100% - 极端的鱼眼畸变保留是风格，超广角拍建筑的话一定要在拍的时候控制水平 + 垂直。

### 紫边 / 色散

逆光强反差边缘（树枝对着天）会有紫色或绿色边。便宜镜头多。后期一键去掉。

### 散景（Bokeh）

虚化部分的视觉质感。圆滑、二线性、洋葱圈、漩涡 - 都是散景的描述。

新手特别迷恋"奶油虚化"，但**散景质感和镜头光学结构有关，不能强求**。Sigma Art 系列的散景不如 Sony GM、不如 Zeiss、远不如 Leica - 但它便宜一半。

如果你不在拍商业人像，散景 quality 可以排在画面 quality 之后。

## 5.7 一颗定焦：最有效的进步路径

**这本书最强的一句话建议**：

> 买一颗定焦（推荐 35mm 或 50mm），用它一年。不要换。

理由：

- 视角变成你的本能。看一个画面就知道这颗镜头能不能拍到
- 习惯了用脚和身体替代变焦
- 节约时间和注意力
- 节约钱
- 你拍出来的片子开始有"风格"

如果你已经有几颗镜头：从今天开始，**强迫自己只带一颗出门 30 天**。30 天后你不会想再变焦。

## 5.8 推荐组合（按预算）

**够用组（5000 RMB 以内）**：
- 二手机身（Sony A7II / Canon RP / Fujifilm X-T3）
- 一颗 35mm 或 50mm 定焦（原厂 f/1.8 系列就够）

**进阶组（10000-20000 RMB）**：
- 全画幅二手机身（Sony A7III / A7C / Canon R6）
- 35mm f/1.4 或 50mm f/1.4（Sigma Art 二手）
- 加一个长焦定焦（85mm f/1.8）

**两颗镜头打天下**：
- 35mm + 85mm 是最经典组合
- 35mm + 50mm 是最街头组合
- 28mm + 50mm 是最 Bresson 组合

**风光特化**：
- 16-35mm f/4 或 17-40mm f/4
- 24-70mm f/4
- 三脚架 + 滤镜（CPL + ND）

**人像特化**：
- 85mm f/1.4
- 35mm f/1.4
- 反光板（便携 5 合 1，便宜）

不要一上来就买"挂机牛头"。三颗 1000 块的定焦比一颗 30000 块的 24-70 让你进步快十倍。

## 5.9 几个反直觉的镜头判断

### 长焦不是"懒人镜头"

新手觉得 200mm "拉近就行"，但长焦其实更难：

- 视角窄，构图选择少
- 浅景深更难合焦
- 慢快门必须三脚架
- 主体很小一点，画面里的细节就很关键

会用 200mm 拍出好片的人，技术比用 35mm 的更扎实。

### 大光圈定焦在弱光下不一定首选

f/1.4 弱光大法是新手的迷信。事实是：

- 现代相机 ISO 6400 完全可用，ISO 12800 大部分场景能接受
- f/1.4 景深太浅，弱光下对焦更难
- f/1.4 镜头比 f/2.8 重很多

弱光场景 ISO 推一档比把光圈开大一档更安全。

### 长焦人像不一定比短焦人像高级

85mm/135mm 的"虚化奶油"让新手以为这就是高级。其实：

- 35mm 拍人像让画面有空间感、故事感、生活感
- 85mm 拍人像把人从环境剥离，干净但冷
- 50mm 是平衡

如果你的人像题材是讲一个人和他生活的关系，35mm 比 85mm 强。

## 5.10 小结

- 焦段不是远近，是空间被压缩还是拉伸
- 35mm 是最值得的第一颗定焦
- 心理距离：广角让观众"在场"，长焦让观众"凝视"
- 景深要传达关系，不要为了虚化而虚化
- 站位变了透视就变了，不要靠换镜头解决距离问题
- 大部分镜头在 f/5.6-f/8 最锐
- 一颗定焦用一年，进步比换器材快

## 5.11 练习

**练习 5.1：定焦一个月。**
挑一颗定焦（35 或 50），一个月只用它出门。一个月后回看你拍的所有片，会发现你看世界的方式被这颗镜头塑造了。

**练习 5.2：透视实验。**
找一个朋友。让他站定。你用同一颗镜头（推荐 50mm 或 35mm）从近到远每隔一米拍一张，10 张。回家排开看主体大小和背景关系如何变。

**练习 5.3：景深实验。**
对同一个静物（咖啡杯、花、人脸），同一站位，从 f/1.4 到 f/16 每档拍一张。对比看景深差异和锐度差异。建立你对各档景深的直觉。

**练习 5.4：焦段对比。**
如果你有变焦镜头：站定不动，从 24mm 到 200mm 每个常用焦段（24/35/50/85/135/200）拍同一画面。回家看每张的"心理距离"和空间感。这是建立焦段直觉的最快方法。

**练习 5.5：35mm 街头练习。**
带 35mm 定焦出门 2 小时。规则：所有片要走到主体 3 米内才能按。拍 100 张，回家选 5 张。
