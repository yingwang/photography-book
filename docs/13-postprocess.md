# 第 13 章 后期

> 后期不是修补。后期是判断的延伸。一张本身没拍好的片，后期救不回来。一张拍对了的片，后期是把"对"变成"好"的最后一公里。

## 13.1 后期的位置

后期在工作流里的位置很关键：

```
看见 → 拍 → 选 → 后期 → 输出
              ↑
        关键决定在这里发生
```

**选片在后期之前**。如果你不选片就直接打开所有片开始调色，会浪费 10 倍时间，最后挑出来的也不是最好的。先选，后调。第 14 章会讲选片。

## 13.2 后期的两种态度

### 态度一：保留风格

后期是**强化你拍的时候已有的判断**。

- 拍的时候光是侧光，戏剧性强 → 后期把暗部压更暗，强化戏剧
- 拍的时候颜色克制 → 后期保持饱和度低
- 拍的时候构图干净 → 后期保持极简
- 拍的时候氛围温暖 → 后期保留暖调

每张片的后期方向**由原片本身的气质决定**。不是你给一张片"加效果"，是你**让原片的气质更鲜明**。

### 态度二：风格化（Stylization）

把原片改造成另一个风格。

- 加电影色（lift / gamma / gain 调色）
- 套预设 / LUT
- Faux Film Look（仿胶片）

风格化没问题，但有两个原则：

- **整组统一**：一组里 30 张都是同样风格化，不是一张一个样
- **不要救废片**：风格化救不了构图差的片。Pretty Filter 上一张构图差的片还是构图差

新手第一年容易迷恋风格化（特别是 Tomato 红、青橙、电影黑白）。第三年会回到态度一 - **后期为画面服务，不为效果服务**。

## 13.3 软件选择

| 软件 | 价格 | 优点 | 缺点 |
|------|------|------|------|
| Lightroom Classic | 订阅 ¥98/月 | 业界标准、生态全 | 订阅、卡 |
| Capture One | ¥299/月 或 ¥1500 买断 | 色彩好、Tether 强、人像友好 | 学习陡 |
| Photoshop | 订阅 | 终极工具 | 不为照片设计 |
| DxO PhotoLab | ¥1100 买断 | 镜头校正、降噪强 | 工作流弱 |
| Affinity Photo | ¥250 一次买断 | 便宜、强 | 生态弱 |
| Apple Photos | 免费 | 集成、方便 | 高级工具弱 |
| Snapseed (手机) | 免费 | 免费、强 | 屏幕小 |
| VSCO (手机) | 部分免费 | 滤镜美 | 工具弱 |

**推荐**：

- **入门 + 中级**：Lightroom Classic
- **人像 / 棚拍 / 商业**：Capture One
- **手机 + 简单调色**：Snapseed 免费就够
- **预算 100% 免费**：Darktable（开源，强但难学）

不要为了"专业"上 Photoshop 修日常照片。Photoshop 是合成 / 修复工具，不是调色工具。

## 13.4 通用工作流

不管软件什么，后期工作流大致一样：

```
1. 导入 + 选片
2. 全局调整：白平衡、曝光、对比、高光阴影
3. 局部调整：径向、笔刷、渐变
4. 色彩：HSL、Color Grading
5. 锐化 + 降噪
6. 镜头校正、裁剪、透视
7. 输出
```

新手最常见错误：**步骤 1 和步骤 6 的次序乱**。先裁剪（决定构图），再调色 - 因为色彩判断要看到最终构图。然后最后再输出（一些设置如锐化和导出格式相关）。

## 13.5 全局调整：六个滑块

Lightroom 的"基本"面板里六个滑块。一张片的 80% 在这里完成。

### 滑块一：曝光（Exposure）

整张图变亮变暗。

- 拉亮：+0.3 ~ +1
- 拉暗：-0.3 ~ -1.5
- 注意：拉太多会损细节

经验：先调曝光让**主体亮度**对，不是整张亮度对。

### 滑块二：对比度（Contrast）

整张反差。

- 拉正：暗部更暗、亮部更亮
- 拉负：暗部变亮、亮部变暗

经验：**对比度不要直接拉**。用高光阴影 + 黑白色阶分别控更精细。直接拉对比度往往让中间灰被压扁。

### 滑块三：高光（Highlights）

只动亮部。

- 拉负（-50 ~ -100）：拉回过曝高光（天空、白衣服）
- 拉正：让亮部更亮（很少用）

经验：**第一个动的就是这个**。先把高光拉回来，画面立刻不刺眼。

### 滑块四：阴影（Shadows）

只动暗部。

- 拉正（+30 ~ +70）：暗部细节出来
- 拉负：暗部更暗、戏剧性强

经验：阴影拉太多会让画面"假" - 暗部本来就该有暗部。+30 ~ +50 是上限，**不要为了"看清细节"什么都拉**。

### 滑块五：白色色阶（Whites）

最亮的那一档。

- 拉正：让最亮处更亮（接近纯白）
- 拉负：压住最亮

经验：和高光配合用。先拉负高光（压回过曝），再拉正白色色阶（恢复活力）。

### 滑块六：黑色色阶（Blacks）

最暗的那一档。

- 拉负：让最暗处更暗（接近纯黑）
- 拉正：暗部不死黑

经验：**新手常常忘了拉黑色色阶**。一张片缺死黑就缺力量。常规调整都该拉 -10 ~ -30 黑色色阶。

### 六个滑块的常用组合

记几个常用组合（数值仅供起步参考）：

**风光戏剧**：高光 -60 / 阴影 +40 / 白色 +20 / 黑色 -30 / 对比 +20

**人像柔和**：高光 -30 / 阴影 +30 / 白色 0 / 黑色 -10 / 对比 0

**电影感低反差**：高光 -40 / 阴影 +60 / 白色 -20 / 黑色 +20 / 对比 -10

**高反差街头**：高光 -50 / 阴影 -20 / 白色 +30 / 黑色 -50 / 对比 +30

但**不要套用**。每张片都不一样。组合只是参考起点。

## 13.6 局部调整

全局之后用局部。

### 工具一：径向 / 椭圆

主体周围画一个椭圆，对里面或外面调整。

最常用：

- 主体周围画椭圆，**外面**减曝光（暗角效果，把视线推向中间）
- 主体周围画椭圆，**里面**加曝光（聚光效果）
- 主体周围画椭圆，里面加 +5 锐化（让眼睛更锐利）

### 工具二：渐变（Linear Gradient）

线性渐变，用于天地分明的场景。

最常用：

- 风光：从画面顶部往下拉渐变，减曝光（压住天空）
- 风光：从画面底部往上拉渐变，加曝光（提前景）
- 模拟 GND 滤镜效果

### 工具三：笔刷 / 蒙版

任意形状选区，最灵活。

最常用：

- 选主体，加锐化 + 微提亮 + 微饱和
- 选背景，减锐化 + 微减饱和（让背景退后）
- 选眼睛 + 加锐化 + 加亮（让眼神突出）
- 选皮肤，磨皮（笔刷反向：减锐化 + 减质感）

现代 AI 蒙版（Lightroom 11+ / Capture One 23+）一键选主体 / 天空 / 人物 / 皮肤 / 头发，比手动笔刷快十倍。

### 局部调整的"度"

经验：**全局 70%，局部 30%**。如果你 90% 用局部调整，原片可能就拍得不够好。

特例：人像。人像后期很多在皮肤、眼睛、头发的精细控制。局部占 50% 也合理。

## 13.7 色彩调整

### HSL（色相/饱和度/亮度）

8 个色相通道：红、橙、黄、绿、青、蓝、紫、品。每个通道有 H/S/L 三个值。

**最常用 HSL**：

- 拍人像：橙通道（皮肤）饱和度 -10、亮度 +5（让皮肤干净）
- 拍蓝天：蓝通道饱和度 +10、亮度 -10（让天更蓝更深）
- 拍秋叶：黄红通道饱和度 +15（让秋色更浓）
- 减绿：绿通道饱和度 -15（很多场景绿太鲜艳，压一下变沉稳）

**新手陷阱**：所有通道都拉到 +50。拉到极端 = 假滤镜感。**±15 是合理范围**，超过就要小心。

### Color Grading（色彩分级）

Lightroom 11+ 把"分离色调"升级为 Color Grading。三轮（高光、中调、阴影）+ 全局。

**最经典电影色**：

- 高光偏橙（+黄绿）
- 阴影偏青蓝（蓝橙互补）

**复古胶片**：

- 高光偏黄
- 阴影偏紫

**冷峻**：

- 全部偏蓝
- 阴影更深的蓝

Color Grading 的强度小心。**每个色轮的强度（Luminance / Hue 滑块）一般在 20-40 之间**。新手习惯拉到 100 = 假。

### 白平衡

拍 RAW 才有真正的白平衡控制。

- 暖：3000-4000K（暖灯下、暖调氛围）
- 中性：5000-5500K（多数场景）
- 冷：6500-8000K（蓝调时刻、冷峻）

**色温在 ±500K 内调整都安全**。±1000K 以上会让画面感觉"失真"。

色调（Tint）：绿到品红。在荧光灯混色光下用得多。

## 13.8 锐化与降噪

### 锐化

Lightroom 锐化默认值（数量 25 / 半径 1 / 细节 25）适合大多数场景。

**进阶**：

- 风光：数量 50-70 / 半径 1 / 细节 30-50（强调纹理）
- 人像：数量 20-30 / 半径 1 / 细节 0-15（不要锐化皮肤）
- 高 ISO：数量 30 / 半径 0.5 / 细节 0（不放大噪点）

**蒙版**（Mask）滑块：按住 Alt 拖动，可以让锐化只作用在边缘，不锐化平滑区域（皮肤、天空）。**这是被新手忽略的滑块**。

### 降噪

ISO 6400+ 的片需要降噪。

**Lightroom 经典降噪**（亮度 + 颜色）：

- 亮度：20-40（噪点平滑度）
- 颜色：30-50（彩色噪点去除）

**Lightroom AI 降噪**（v12+）：

- 一键，强度 30-50
- 降噪质量比经典强一档以上

**Topaz DeNoise AI / Photo AI**：

- 独立软件，效果比 Lightroom 还好
- 几百块买断

降噪的"度"：

- 50% 噪点 = 保留质感
- 80% 噪点 = 干净但塑料感
- 100% 噪点 = 假塑料

经验：**降噪不要拉到极致**。留 20-30% 颗粒感。

## 13.9 RAW 后期的"宽容度"

拍 RAW 给你的后期空间：

- 曝光 ±2 档：可救
- 高光 +1 档过曝：勉强救（看相机和镜头）
- 高光 +2 档以上过曝：救不回（数据真没了）
- 阴影 -3 档欠曝：可救（推回来会有噪点，但有细节）
- 阴影 -4 档以上欠曝：极弱

**所以拍的时候宁欠勿过**。但 ETTR 策略是"在不爆的前提下尽量推到右"。两者不矛盾。

## 13.10 一致性：建立你的预设

如果你的所有片每张都重新调色，你的图册看起来不像一个人拍的。

**建立 1-3 个你常用的"预设"**：

- 你的"街头预设"（Lightroom 里建一个 Profile + Preset）
- 你的"人像预设"
- 你的"风光预设"

每张片用对应预设作起点，再微调。

效果：

- 一组里所有片有统一感
- 节约 80% 调色时间
- 你的图册有"风格"

新手追求"每张片都是独立艺术品"。十年的人追求"一组里统一"。

## 13.11 几个常见后期错误

### 错误一：HDR 拉过头

阴影 +100 + 高光 -100 + 黑白色阶都中性 = 油画感、假 HDR。

修正：阴影 +30、高光 -50、黑色 -20、白色 +10 - 让画面有层次。

### 错误二：饱和度拉满

理由是"鲜艳"。结果：肤色变橘子皮、阴影变脏、过渡断层。

修正：饱和度 0 或 -10。Vibrance（自然饱和度）+10。HSL 分通道控制。

### 错误三：磨皮过度

人像皮肤磨成塑料。鼻子下巴失去结构。

修正：

- 磨皮笔刷：纹理 -20，清晰度 -10。**不要更多**。
- 用频率分离（Frequency Separation）保留肌理
- 局部修复（污点 / 痘痘），不是整脸 blur

### 错误四：过度锐化

锐化拉到 +100。结果细节边缘出"白边"，画面像 90 年代电视。

修正：锐化数量 30-50，蒙版 30-60，**不要过 80**。

### 错误五：过度暗角

四周都黑了一圈。可能强调了主体，但很明显是后期。

修正：暗角 -10 ~ -20 是合理范围。**主体不在中心时不要加暗角**。

### 错误六：白平衡拉到极端

为了"日落感"把整张拉到 8000K。整张橘色。

修正：白平衡微调（±300K）。氛围用 Color Grading 加。

## 13.12 后期审美的进步

后期审美和拍摄判断是同步进步的。建立审美的方法：

**方法一：看摄影画册**

- Magnum 摄影师：Bresson, Capa, Salgado, Webb
- 风光：Galen Rowell, Marc Adamus, Michael Kenna
- 人像：Lindbergh, Avedon, Penn
- 街头：Vivian Maier, Saul Leiter, Daido Moriyama

看实体画册（不只是 Instagram）。色彩、纸感、印刷的层次教你后期的"度"。

**方法二：分析自己最满意的 10 张片**

调色有什么共同点？反差、色温、饱和度、锐化的强度？这是你天生的偏好。

**方法三：极端测试**

把一张片做 5 个极端版本（极冷、极暖、极对比、极饱和、极平淡）。比较哪个最贴近你想表达的。

**方法四：限制后期工具**

只用 6 个基本滑块调一周，不用 HSL、不用 Color Grading、不用预设。这会让你看清"基本调整能做多少"。

## 13.13 小结

- 后期是判断的延伸，不是修补
- 选片在前，后期在后
- 全局 70% + 局部 30% 是合理比例
- 六个滑块（曝光/对比/高光/阴影/白色/黑色）覆盖 80% 工作
- 局部用径向、渐变、AI 蒙版
- HSL 分通道控制色彩，每通道 ±15 内
- 拍 RAW 给你 ±2 档曝光空间
- 建立 1-3 个常用预设给图集统一感
- 避免六个常见错误：HDR 过头、饱和过满、磨皮过度、锐化过度、暗角过重、白平衡极端

## 13.14 练习

**练习 13.1：六个滑块。**
找一张原片，**只用基本面板的 6 个滑块**（不用任何其他工具），尝试做出最满意的版本。30 分钟。一周做 7 张。

**练习 13.2：极端版本对比。**
一张片做 5 个版本：极冷、极暖、高反差、低反差、原片对比。并排看。决定哪个最贴近原意图。

**练习 13.3：建立你的预设。**
找你最满意的 5 张片。看它们的共同点（白平衡、对比、饱和、调色）。把这些值保存为一个 Preset，命名"我的"。一个月只用这个 Preset 起步，每张微调。

**练习 13.4：HSL 通道练习。**
拍一张人像、一张蓝天、一张秋叶。每张分别玩 8 个通道。看哪个通道对画面影响最大。建立你对 HSL 的直觉。

**练习 13.5：1 张片调 10 次。**
找你 5 年前不满意的一张片，今天重新调。30 分钟。完成。然后**关掉 Lightroom，第二天再调**。10 天每天调一次。10 天后看 10 个版本。哪个最好？为什么？
