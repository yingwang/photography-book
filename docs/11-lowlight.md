# 第 11 章 弱光与夜景

> 弱光不是缺光，是另一种光。它的色彩、氛围、情绪和白天完全不同。这一章讲怎么让相机在 ISO 6400 以上还出片。

## 11.1 弱光的两种世界

弱光场景大致分两类，处理逻辑不同。

### 世界一：环境弱光（Ambient Low Light）

光本身就是少的。咖啡馆夜里、博物馆室内、教堂内部、家里晚上、乡村夜晚。

特征：

- 光源单一或少数（窗、台灯、烛光）
- 整体暗调
- 局部高亮（光源附近）反差大
- 颜色温度低（暖、橙、黄）

**这一类是最有故事感的弱光**。氛围浓、颜色厚、情绪强。

### 世界二：人造光主导（Artificial Light Dominated）

夜晚城市、霓虹街区、舞台、演唱会。

特征：

- 多光源、混色严重
- 局部极亮（霓虹、聚光）
- 反差非常大
- 颜色饱和、跳

**这一类视觉冲击强、但对画面整理要求更高**。色彩混乱很容易出脏片。

两类的器材逻辑、参数逻辑、构图逻辑都不一样。下面分开讲。

## 11.2 弱光器材

### 相机的高 ISO 性能

现代相机的高 ISO 表现：

| 相机 | 干净 ISO 上限 | 可用 ISO 上限 |
|------|--------------|--------------|
| 全画幅旗舰（A1 / R1 / Z9）| 12800 | 25600-51200 |
| 全画幅中端（A7IV / R6 / Z8）| 6400 | 12800-25600 |
| APS-C（X-T5 / X100VI / R7） | 3200 | 6400-12800 |
| M43（OM-1 / GH7） | 1600 | 6400 |
| 手机（iPhone 16 Pro / Pixel 9） | 800 | 3200（计算合成） |

"干净"指噪点不影响画面，"可用"指能用但有噪点（可后期降噪 / 接受）。

弱光的真理：**全画幅有显著优势**。如果你认真做弱光，全画幅是回不去的。

### 镜头：大光圈是关键

弱光场景下镜头光圈每多一档 = ISO 少一档 = 噪点少一档。

**最值得在弱光投资的镜头**：

- 35mm f/1.4
- 50mm f/1.4
- 85mm f/1.4 或 f/1.8
- 24mm f/1.4
- 24-70mm f/2.8（变焦极限）

f/1.4 vs f/2.8 = 2 档光 = 弱光下 ISO 从 6400 降到 1600，画质差距巨大。

### 三脚架

如果是静态主体（建筑、风光、静物），三脚架解决一切。ISO 100 + 30s 慢门 = 任何弱光都能拍。

### 闪光灯（按需）

环境弱光里加一盏小灯（持续 LED，闪光灯都行）能补主体。

但**要克制**：太亮的闪光会破坏弱光的氛围。-1 ~ -2 EV 用为补充。

## 11.3 弱光参数策略

### 策略一：手持人物 / 抓拍

不能用三脚架的弱光场景。

- 模式：M + Auto ISO，或 A 模式
- 光圈：尽量大（f/1.4-2.8）
- 快门：1/100s 起（焦段越长越要快），最低 1/60s（防抖加持下）
- ISO：Auto，上限设到你的相机可用极限（全画幅 12800-25600）
- 对焦：单点 + 后键对焦
- 测光：评价
- 曝光补偿：-0.7 ~ -1（弱光场景往往要保留暗调氛围，不要过曝把氛围拉成白天）

### 策略二：静态 / 三脚架

风光、建筑、夜景。

- 模式：M
- 光圈：f/8（最锐 + 全景深）
- 快门：根据需要慢门（1-30s）
- ISO：100
- 三脚架 + 快门线 / 自拍计时
- 长曝光降噪可开（耗时间但降噪效果好）

### 策略三：极弱光 / 星空

银河、星轨、极光。

- 三脚架
- f/1.4 ~ f/2.8 大光圈
- 快门：5-25s（500 法则：500 / 焦距 = 不出星轨的最长曝光秒数）
- ISO：3200-6400
- 手动对焦到无穷远（用 Live View 放大对焦星星）
- 拍 RAW

## 11.4 处理弱光的几个判断

### 判断一：噪点 vs 模糊

弱光下你必须选其中一个：

- 高 ISO（噪点）但快门快（清楚）
- 低 ISO（干净）但快门慢（运动模糊）

哪个更糟？要看主体：

- 拍静物 → 慢快门，三脚架，0 噪点
- 拍人物 → 高 ISO，快快门，避免动模糊（动模糊救不回，噪点能后期）
- 拍街头 → 高 ISO + 1/60-1/250s，接受微动模糊作为风格

**新手陷阱**：为了 ISO 100 把快门拖到 1/15s，主体一动就糊。回家发现 100% 都不能用。

### 判断二：保氛围 vs 提亮主体

弱光场景的"对的曝光"通常**不是主体亮如白昼**。

例：咖啡馆里一个人在窗边读书。

- 错的：把人脸提到正常亮度，整张片像白天
- 对的：保留咖啡馆的暗调，让人脸略亮（不是中亮）但环境压暗

判断：**画面的氛围是什么？暖、暗、安静？保留它**。曝光补偿 -1 ~ -1.5 经常是对的。

### 判断三：要不要去噪点

ISO 6400 的片有噪点。新手第一反应：拉降噪。

但降噪是有成本的：

- 损失细节（皮肤变塑料、毛发变涂抹）
- 损失锐度
- 颜色会被平滑化

经验：

- 噪点不一定全消除。**适度降噪**留 30% 噪点，画面更"film 感"
- 用 AI 降噪（Topaz DeNoise / Lightroom AI Denoise）效果好得多
- 黑白片可以保留更多噪点（噪点像胶片颗粒）

**噪点不是必死的废**。彩色片要适度降噪，黑白片可以拥抱噪点。

## 11.5 几种典型弱光场景

### 场景一：咖啡馆 / 餐厅

光源：窗光（白天）+ 暖灯（晚上）

策略：

- 35mm 或 50mm f/1.4-2
- ISO 1600-6400
- 1/100s 起
- 找主体在窗边或灯下
- -0.7 EV 保留暖调

陷阱：混色光。如果窗光（5500K）+ 暖灯（3000K）同时存在，色温会混乱。处理：

- 选一种光（坐在远离窗户的位置，让暖灯主导）
- 或后期分区调白平衡

### 场景二：博物馆 / 教堂

极暗，禁止三脚架，禁止闪光灯，禁止说话。

策略：

- 35mm f/1.4
- ISO 6400-12800
- 1/60s 极限（靠柱子 / 靠墙增加稳定）
- -0.7 EV
- 单点 AF，对焦到主体（雕塑、彩窗、人）
- 拍 RAW

### 场景三：街头夜景

霓虹、路灯、橱窗、车灯。

策略：

- 35mm f/2-2.8（不要全开 f/1.4，景深太浅夜里更难对焦）
- ISO 3200-12800
- 1/125s 起（人在动）
- 找单一主色（红、蓝、绿、橙）当画面 dominant
- 主体放在被光照亮的位置（聚光效应）

### 场景四：演唱会 / 舞台

聚光灯，主体亮，背景全黑。反差极大。

策略：

- 70-200 f/2.8 或 85 f/1.4
- ISO 6400-25600
- 1/500s 起（动作快）
- 点测光对主体
- 曝光补偿 -1（聚光本身亮，要保高光）
- 连拍 + AF-C
- 拍 RAW

陷阱：演唱会的混色光（红、蓝、绿、紫频繁切换）会让连拍里每张色温都不同。后期统一处理。

### 场景五：城市夜景（建筑 / 天际线）

蓝调时刻或全黑夜。

策略：

- 三脚架
- f/8-11
- ISO 100-200
- 5-30s 慢门
- 蓝调时刻最佳（天还有蓝，灯已经亮）
- 拍 RAW
- 包围曝光（HDR 合成）

### 场景六：星空 / 银河

无光污染地，新月夜，晴朗。

策略：

- 三脚架 + 必备
- 14-24mm f/2.8 或 35 f/1.4
- ISO 3200-6400
- 快门 15-25s（500 法则）
- 手动对焦到无穷远
- 拍 RAW
- 多张堆栈（5-10 张同参数 + 软件合成 = 降噪）
- 配合前景（一棵树、一座山、一个人）出"环境星空"

陷阱：

- 月光太强，等无月夜
- 灯光污染（城市附近不行，要去 SQM 21+ 的地方）
- 镜头大光圈在边缘容易彗差（星变成"飞鸟形"），后期裁掉边缘

### 场景七：极光

极地特殊场景。

策略：

- 三脚架 + 重要的耐寒衣物
- 14-24 f/2.8 或 24 f/1.4
- ISO 1600-6400
- 快门 3-15s（强极光只需 3s，弱极光要 15s）
- 手动对焦到无穷远
- App 监控：My Aurora Forecast

陷阱：

- 温度 -30°C 电池掉电极快，多带备用，揣胸口里
- 三脚架金属冷到粘手，戴薄手套
- 镜头进出室内外起雾，等温度平衡

## 11.6 弱光的色彩

弱光场景的色彩处理是一个独立题目。

### 暖光（钨丝灯、烛光、暖色 LED）

特征：橙黄、温暖、亲密

处理：

- 不要白平衡校正到完全中性（会失去暖调氛围）
- 留 70-80% 的暖
- 黑色不要拉到中灰
- 整体压暗一点

### 冷光（荧光灯、冷白 LED、月光）

特征：青白、冷峻、距离感

处理：

- 留 70-80% 的冷
- 加点紫蓝深暗部
- 适合黑白转换

### 霓虹混色（夜景商业街）

特征：红 + 蓝 + 绿 + 紫多色 + 高饱和

处理：

- 选一种主色让其他色压暗
- 拉低整体饱和（霓虹本身已经够饱和，不需要加）
- 局部分区调色（让红的更红、蓝的更蓝、其他色压灰）

### 蓝调时刻

特征：蓝紫色天空 + 暖色灯亮

处理：

- 这是最好处理的弱光场景之一
- 蓝橙互补天然对比
- 不需要太多调整

## 11.7 弱光的构图

弱光的特殊性：**画面里的暗部是构图的一部分**。

### 思维一：让暗部当框

主体被光照亮，周围一圈暗。暗部本身不需要"内容"，它就是画框。

例子：

- 一个人脸被一束光打到，周围全黑
- 一栋建筑窗户亮着，周围全黑
- 一个街角路灯下的人，其他全暗

这种"光池"构图是弱光最有力量的形式。

### 思维二：低调（Low-Key）

整张画面以暗调为主，亮部只占 10-30%。

低调画面的力量：

- 神秘
- 凝重
- 让眼睛聚焦在亮部
- 高级感（高饱和明亮的画面看起来"轻"）

低调适合：人像（戏剧性）、夜景、室内、黑白

### 思维三：剪影

让主体只剩轮廓，背景有光（夜空、灯、霓虹）。

剪影构图的关键：

- 主体轮廓必须清晰可识别（一个人、一只手、一只猫）
- 主体内部完全黑（不要救它）
- 背景要亮且简单（一面亮墙、一面天空）

## 11.8 弱光的后期

弱光的后期工作量比白天大。常见步骤：

1. **白平衡**：决定保留暖调还是中性
2. **降噪**：AI 降噪一键，但保留 30% 噪点
3. **色调曲线**：拉黑黑场（让最暗变更暗），不要把暗部都提亮
4. **饱和度**：降低（弱光的真实感来自克制的色彩）
5. **锐化**：保守（高 ISO 锐化 = 放大噪点）
6. **局部光线**：用径向 / 蒙版给主体加一点光

**最大的陷阱**：把弱光后期拉成"白天"。氛围全没了。

判断：后期完成后，"这张是夜晚拍的"还是"这张是白天 + 蓝色滤镜"。如果像后者，拉过头了。

## 11.9 小结

- 弱光分两种：环境弱光、人造光主导
- 全画幅 + 大光圈定焦是弱光首选
- 高 ISO（噪点）vs 慢快门（模糊）必选其一
- 保氛围比提亮主体更重要
- 适度降噪保留 30% 噪点，黑白可保更多
- 不同弱光场景有不同策略：咖啡馆暖、夜景霓虹、星空银河、极光
- 弱光的暗部是构图的一部分
- 后期不要把弱光拉成白天

## 11.10 练习

**练习 11.1：咖啡馆人像。**
找一个咖啡馆，靠窗或暖灯下。拍一个朋友 30 张。35 或 50mm f/1.4-2，ISO 自动。回家选 5 张。判断哪些保留了氛围。

**练习 11.2：高 ISO 测试。**
在弱光下连拍同一画面，从 ISO 800、1600、3200、6400、12800、25600。回家 100% 看噪点。**找出你能接受的 ISO 上限**。这是你以后弱光的红线。

**练习 11.3：剪影。**
傍晚 / 夜里，找一个亮背景（窗、霓虹、街灯）。让一个主体（人 / 物）站在前面拍剪影。30 张选 5 张。

**练习 11.4：城市夜景。**
蓝调时刻一个城市制高点。三脚架 + f/11 + ISO 100 + 长曝光。拍一组（不同曝光时间）。

**练习 11.5：低调人像。**
室内单灯（一盏台灯、一个手电、一个手机闪光灯）。拍一个朋友。要求：80% 画面是暗的，20% 是被光照亮的脸 / 手。
