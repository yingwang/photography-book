# 第 11 章 弱光与夜景

> 弱光不只是光不够。它是另一种光线状态，色彩、氛围和情绪都和白天不同。

---

1932 年冬天的某个晚上，匈牙利摄影师 Brassaï 走在巴黎一条 Latin Quarter 的小街上。雪刚停，路灯下有薄雾。他停下来对着一面被雪盖住的墙拍 - 用 6×9 的相机，f/4.5，曝光 30 秒。

回家冲出来一看，这张照片**让人感觉巴黎在那个深夜独自醒着**。墙上的雪有蓝色的反射，路灯是橙黄的，雾把光晕成一圈一圈。这是巴黎当时几乎没人拍过的样子。

他后来 4 年都在拍这种巴黎夜景。1933 年出了书《Paris de nuit》（《夜巴黎》），震惊了当时的摄影圈。他的方法很简单 - **在白天人都睡了的城市里走，等光让一个本来熟悉的地方变得陌生**。

弱光摄影的核心思路，不应该只是「光不够，应该怎么补」。更重要的问题是：光少了以后，画面里的东西怎样被重新分配？哪些地方会消失，哪些地方反而会被强调？你要学会看见这种新的分配。

白天巴黎是观光的，夜里巴黎是 Brassaï 的。同一个城市，光不一样，是两个城市。

---

弱光场景大致分两类，处理逻辑不同。

**环境弱光**（Ambient Low Light）的光本身就是少的。咖啡馆夜里、博物馆室内、教堂内部、家里晚上、乡村夜晚 - 光源单一或少数（一扇窗、一盏台灯、一支烛火），整体暗调，光源附近一圈亮，离开光源迅速衰减成暗。颜色温度低，全画面笼在橙、黄、暖红里。这一类是最有故事感的弱光：荷兰画派 Vermeer 几百年前画的就是这种光（一扇侧窗 + 一个室内人），他用油画干的事和你今天用 35mm f/1.4 干的是同一件事 - 把那点儿光的温度留下。氛围浓、颜色厚、情绪强。

**人造光主导**（Artificial Light Dominated）。夜晚城市、霓虹街区、舞台、演唱会。多光源、混色严重，局部极亮（霓虹、聚光），反差非常大，颜色饱和、跳。香港旺角和东京新宿夜里的街道是教科书例子 - 红色招牌打在脸上，蓝色 LED 打在墙上，街尽头一道绿色霓虹，每个色温都不一样。**这一类视觉冲击强，但对画面整理要求更高**：色彩混乱很容易出脏片，要么选一种主色压住其他，要么干脆走杂乱本身的力量。

两类的器材、参数、构图都不一样。

---

弱光里有一个很现实的规律：**全画幅有显著优势**。如果你长期认真拍弱光，迟早会感受到更大传感器带来的余量。高 ISO、更干净的暗部和更稳定的动态范围，都会让弱光拍摄轻松很多。

现代相机的高 ISO 表现：全画幅旗舰（A1 / R1 / Z9）干净 ISO 上限 12800，可用 ISO 上限 25600-51200。全画幅中端（A7IV / R6 / Z8）干净 6400，可用 12800-25600。APS-C（X-T5 / X100VI / R7）干净 3200，可用 6400-12800。

弱光场景下镜头光圈每多一档 = ISO 少一档 = 噪点少一档。最值得在弱光投资的镜头是 35mm f/1.4、50mm f/1.4、85mm f/1.4 或 f/1.8、24mm f/1.4、24-70mm f/2.8。**f/1.4 vs f/2.8 = 2 档光 = 弱光下 ISO 从 6400 降到 1600，画质差距巨大**。

如果是静态主体（建筑、风光、静物），**三脚架解决一切**。ISO 100 + 30s 慢门 = 任何弱光都能拍。

闪光灯仍然只是工具，不是污点。环境弱光里加一盏小灯，无论是持续 LED 还是闪光灯，都可以让主体从暗部里出来。关键是克制。闪光太亮时，弱光本来的氛围会被直接打碎。把补光压到 -1 到 -2 EV，通常更像是在现场原有光线里轻轻补了一点。

---

不能用三脚架的弱光场景，比如咖啡馆人物 / 抓拍。M + Auto ISO 或 A 模式，光圈尽量大（f/1.4-2.8），快门 1/100s 起（焦段越长越要快），ISO Auto 上限设到你的相机可用极限，对焦单点 + 后键对焦，曝光补偿 -0.7 ~ -1（**弱光场景往往要保留暗调氛围，不要过曝把氛围拉成白天**）。

静态 / 三脚架场景，比如风光、建筑、夜景。M 模式，光圈 f/8（最锐 + 全景深），快门根据需要慢门（1-30s），ISO 100，三脚架 + 快门线 / 自拍计时，长曝光降噪可开（耗时间但降噪效果好）。

极弱光 / 星空。三脚架，f/1.4 ~ f/2.8 大光圈，快门 5-25s（500 法则：500 / 焦距 = 不出星轨的最长曝光秒数），ISO 3200-6400，手动对焦到无穷远（用 Live View 放大对焦星星），拍 RAW。

---

弱光里最让人抓狂的，往往不是噪点，而是对不上焦。光一暗，自动对焦就开始来回拉风箱，怎么也锁不住。这件事有几个固定的破法，值得专门记住。

第一，别让相机去对一片均匀的暗。自动对焦靠的是反差，一面黑墙、一片夜空它都抓不住。把对焦框移到画面里明暗交界的地方，一道边缘、一个灯的轮廓、霓虹字的笔画，相机立刻就能合上。对人也一样，对在眼睛和脸颊的交界、或者头发的亮边上，比对在脸中间更容易成功。

第二，拿光源当对焦目标。夜里最可靠的合焦点就是光本身，一盏路灯、一块招牌、对方手机的屏幕。先对在和主体差不多远的某个亮处，半按锁住，再平移回来构图，也就是先对焦再重构。

第三，自动实在不行就转手动。打开屏幕的对焦峰值（focus peaking）或者放大实时取景，手动拧到主体边缘冒出一圈高亮，就是合上了。拍星空、拍极弱光的风光，本来就该一开始手动对到无穷远，省得相机在黑暗里白费力气。配合前面讲过的区域对焦，把光圈收一点、对到一个估计距离，也能让夜里的抓拍不必每张都重新合焦。

---

弱光下，你经常必须在两种代价之间选择。一种是提高 ISO，接受更多噪点，但换来更快的快门和更清楚的主体。另一种是压低 ISO，让画面更干净，但快门变慢，运动模糊的风险也会增加。

哪个更糟要看主体。拍静物 → 慢快门，三脚架，0 噪点。拍人物 → 高 ISO，快快门，避免动模糊（**动模糊救不回，噪点能后期**）。拍街头 → 高 ISO + 1/60-1/250s，把微动模糊当风格。

新手常见的问题，是为了坚持 ISO 100，把快门拖到 1/15s。只要主体稍微一动，画面就会糊掉。回家之后再看，可能会发现整组照片都没有办法使用。

---

弱光场景里的「对的曝光」，通常**不是把主体提亮到像白天一样**。弱光的价值就在暗部，如果你把暗部全部拉开，氛围也会一起消失。

例：咖啡馆里一个人在窗边读书。错的做法是把人脸提到正常亮度，整张片像白天。对的是保留咖啡馆的暗调，让人脸略亮（不是中亮）但环境压暗。

判断：画面氛围是什么？暖、暗、安静？保留它。**曝光补偿 -1 ~ -1.5 经常是对的**。

---

ISO 6400 的片有噪点。新手第一反应是拉降噪。但降噪有成本：丢细节（皮肤变塑料、毛发变涂抹）、丢锐度、颜色被平滑化。

经验：**噪点不必全消**。适度降噪留 30% 噪点，画面更「film 感」。用 AI 降噪（Topaz DeNoise / Lightroom AI Denoise）效果好得多。**黑白片可以保留更多噪点**（噪点像胶片颗粒）。

噪点不一定会毁掉照片。彩色片可以适度降噪，保留一点质感；黑白片甚至可以更主动地接受噪点，让它接近胶片颗粒的效果。

---

几种典型弱光场景，策略各不同。

**咖啡馆 / 餐厅**。光源：窗光（白天）+ 暖灯（晚上）。35mm 或 50mm f/1.4-2，ISO 1600-6400，1/100s 起，找主体在窗边或灯下，-0.7 EV 保留暖调。陷阱混色光：窗光 5500K + 暖灯 3000K 同时存在，画面里一半人脸冷、一半暖，怎么调白平衡都拧。处理是选一种光让主体只受它照，或后期分区调白平衡。

**博物馆 / 教堂**。极暗，禁止三脚架，禁止闪光灯，禁止说话。35mm f/1.4，ISO 6400-12800，1/60s 极限（靠柱子 / 靠墙增加稳定），-0.7 EV，单点 AF，对焦到主体（雕塑、彩窗、人），拍 RAW。

**街头夜景**。霓虹、路灯、橱窗、车灯。35mm f/2-2.8（不要全开 f/1.4，景深太浅夜里更难对焦），ISO 3200-12800，1/125s 起（人在动）。**找单一主色**（红、蓝、绿、橙）当画面 dominant - Saul Leiter 在 1950 年代纽约就是这么干的，他大量的彩色街头都是先看到一片红或一片绿，再等一个人走进去。主体放在被光照亮的位置（聚光效应）。

**演唱会 / 舞台**。聚光灯下主体亮、背景全黑，反差极大。70-200 f/2.8 或 85 f/1.4，ISO 6400-25600，1/500s 起（动作快），点测光对主体，曝光补偿 -1（聚光本身亮，要保高光），连拍 + AF-C，拍 RAW。陷阱是混色光 - 红、蓝、绿、紫频繁切换，连拍里每张的色温不同，回家后期要分组统一处理。

**城市夜景**（建筑 / 天际线）。蓝调时刻或全黑夜。三脚架，f/8-11，ISO 100-200，5-30s 慢门。蓝调时刻最佳：天还有那一抹深蓝，所有的灯刚刚亮起来 - 这个组合的反差和颜色对比是夜里最舒服的 25 分钟。拍 RAW，包围曝光（HDR 合成）。

**星空 / 银河**。无光污染地，新月夜，晴朗。三脚架，14-24mm f/2.8 或 35 f/1.4，ISO 3200-6400，快门 15-25s（500 法则），手动对焦到无穷远，拍 RAW。多张堆栈（5-10 张同参数 + 软件合成 = 降噪）。配合前景一棵孤树、一座山的轮廓、一个人坐着仰头 - 出「环境星空」而不是只拍一片星点。

**极光**。三脚架 + 耐寒衣物。14-24 f/2.8 或 24 f/1.4，ISO 1600-6400，快门 3-15s，手动对焦到无穷远，App 监控 My Aurora Forecast。-30°C 不是吓人 - 在阿拉斯加 Fairbanks、芬兰 Rovaniemi、挪威 Tromsø 极光季节常常就这个温度。电池每 20 分钟掉一格，得多带几块揣胸口里轮换；三脚架金属冷到沾手撕一层皮，必须戴薄手套；镜头从车里端到外面会立刻起雾，要在外面预冷 10 分钟才能用。

---

弱光的色彩处理是单独一题。

**暖光**（钨丝灯、烛光、暖色 LED）橙黄、温暖、亲密。处理上不要把白平衡校正到完全中性 - 那会让画面失去最珍贵的暖调氛围，变成「白炽灯下的医院」。留 70-80% 的暖，黑色不要拉到中灰，整体压暗一点，让暖光只占领画面一角而不是充满整张。

**冷光**（荧光灯、冷白 LED、月光）青白、冷峻、距离感。留 70-80% 的冷，深暗部加点紫蓝。这种光转黑白特别合适 - 颜色本来就少，去掉之后剩下的反而是它最有力量的样子。

**霓虹混色**（夜景商业街）红 + 蓝 + 绿 + 紫多色 + 高饱和。处理思路是选一种主色，让其他色压暗成陪衬。拉低整体饱和度（霓虹本身已经够饱和），局部分区调色 - 让红的更红、蓝的更蓝、其他色压灰。Saul Leiter 1950 年代在纽约下东区拍的彩色，几乎每张都只有一个主色 dominant，不是因为街上没别的颜色，是他选了一个。

**蓝调时刻**蓝紫色天空 + 暖色灯亮。**最好处理的弱光场景之一**。蓝橙天然互补，反差也刚好，不需要太多调整。

---

弱光的特殊性：**画面里的暗部就是构图的一部分**。

让暗部当框 - 主体被光照亮，周围一圈暗。暗部不需要「内容」，它就是画框。一张脸被一束光打到周围全黑，一栋建筑窗户亮着周围全黑，一个街角路灯下的人其他全暗。**「光池」构图是弱光最有力量的形式**。

低调（Low-Key） - 整张画面以暗调为主，亮部只占 10-30%。神秘、凝重、让眼睛聚焦在亮部、高级感。低调适合人像（戏剧性）、夜景、室内、黑白。

剪影 - 让主体只剩轮廓，背景有光（夜空、灯、霓虹）。关键：主体轮廓必须清晰可识别（一个人、一只手、一只猫），主体内部完全黑，背景要亮且简单。

---

弱光的后期工作量比白天大。

弱光后期最大的陷阱，是把夜晚或暗室硬拉成白天。画面虽然亮了，但原本的氛围也会随之消失。

判断方法很简单。后期完成后，问自己：这张照片看上去像是在夜晚拍的，还是像一张白天照片加了蓝色滤镜？如果更接近后者，说明你拉过头了。

## 练习

找一个咖啡馆，靠窗或暖灯下。拍一个朋友 30 张。35 或 50mm f/1.4-2，ISO 自动。回家选 5 张。看哪些保留了氛围。

弱光下连拍同一画面，ISO 800、1600、3200、6400、12800、25600 各拍一张。回家 100% 看噪点。**找出你能接受的 ISO 上限**。这就是你以后弱光的红线。

傍晚 / 夜里，找一个亮背景（窗、霓虹、街灯）。让一个主体（人 / 物）站在前面拍剪影。30 张选 5 张。

蓝调时刻一个城市制高点。三脚架 + f/11 + ISO 100 + 长曝光。拍一组（不同曝光时间）。

室内单灯（一盏台灯、一个手电、一个手机闪光灯）。拍一个朋友。要求 80% 画面是暗的，20% 是被光照亮的脸 / 手。
