# 事实核查与参考

> 本页只列容易随技术、法律或版本变化而失真的内容。摄影史作品的题名、年代与馆藏信息，优先以收藏机构的公开记录为准；具体机型功能则以该机型最新说明书为准。

## 摄影史与档案 {#photography-history}

- [The Museum of Modern Art：William Eggleston's Guide（1976）](https://www.moma.org/calendar/exhibitions/2079)：展览日期、作品数量与策展信息。
- [The Museum of Modern Art：Photography at MoMA](https://www.moma.org/d/pdfs/W1siZiIsIjIwMTgvMDYvMTMvMWhmaDdhN3BoOF9QaG90b19hdF9Nb01BX1BSRVZJRVcucGRmIl1d/Photo_at_MoMA_PREVIEW.pdf?sha=9610953e3874c1bf)：馆方摄影展览史年表列有 Ernst Haas（1962）、Marie Cosindas（1966）、Helen Levitt（1974）与 Eggleston（1976），因此不把 1976 年写成 MoMA 的“第一次彩色摄影展”。
- [Maloof Collection：Vivian Maier 档案概况](https://www.vivianmaier.com/about-maloof-collection/)：底片、未冲洗胶卷、印片与家庭电影等现存材料的数量说明。
- [Maloof Collection：Vivian Maier 自画像选集](https://www.vivianmaier.com/gallery/self-portraits/)：用公开分类代替未经证实的“几千张自拍”说法。

## 传感器与 RAW {#sensor-and-raw}

- [Adobe：位深的含义](https://helpx.adobe.com/photoshop/using/bit-depth.html)：位深决定可编码的级数，但不应与动态范围直接画等号。
- [Sony：全画幅全域快门的工作方式](https://www.sony.com/en/SonyInfo/technology/stories/entries/9M3_global-shutter/)：卷帘逐行曝光与全域同时曝光的区别。
- [OM SYSTEM：Pro Capture 说明](https://learning.omsystem.com/OM-3/zz_html_manual/en/pro_capture_shooting_115.html)：预拍摄的帧数、对焦与快门限制会随机型和模式变化。

## 色彩管理 {#color-management}

- [International Color Consortium：显示器校准](https://www.color.org/displaycalibration.xalter)：区分把设备调到目标状态的校准，与记录设备实际表现的特性描述。
- [International Color Consortium：ICC profile 简介](https://www.color.org/iccprofile.xalter)：配置文件描述设备或色彩空间，供色彩管理系统完成转换。
- [International Color Consortium：sRGB 与嵌入式配置文件](https://www.color.org/srgb.xalter)：没有配置文件的网络图像通常按 sRGB 解释；带有配置文件时，应由色彩管理系统转换。
- [International Color Consortium：ICC FAQ](https://www.color.org/faqs.xalter)：显示器、打印机与工作空间之间如何通过配置文件建立关系。

## 公开场合人物与建筑 {#public-people-buildings}

法律会变化，而且“拍摄”“公开发布”“商业使用”通常是三件不同的事。出行或发表前，应查拍摄地的现行官方规则；以下链接只是说明本书为何不再提供一张笼统的全球对照表。

- [中国《民法典》人格权编，第 1018–1020 条](https://www.moj.gov.cn/pub/sfbgw/zwgkztzl/2025nianzhuanti/2025mfdxcy/2025mfdxcy_mfdql/202505/t20250507_518708.html)：肖像权与有限的合理使用情形。
- [德国《艺术著作权法》第 22 条](https://www.gesetze-im-internet.de/kunsturhg/__22.html)及[第 23 条](https://www.gesetze-im-internet.de/kunsturhg/__23.html)：公开展示肖像的同意原则与例外。
- [法国《知识产权法》L122-5 第 11 项](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037388886/)：永久置于公共道路上的建筑与雕塑，个人复制的例外明确排除商业使用。

本页不是法律意见。遇到可辨认人物、儿童、私人场所、受版权保护的当代建筑、无人机或商业委托时，优先取得许可。
